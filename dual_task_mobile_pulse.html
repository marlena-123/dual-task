Dual-Task Auditory Probe — Mobile Setup

Experimenter screen. Configure, test the sound, run a practice block, then start the session. Participant taps the screen when they hear a tone.

▸ Advanced settings

Fade in/out is fixed at 10 ms. Anticipation threshold fixed at 100 ms.

What these settings mean
  • ISI min / max (s) — the gap between tones. Each gap is picked at random between these two values, so tones stay unpredictable. Default 15–45 s.
  • First probe not before (s) — a quiet lead-in so the first tone does not arrive immediately after the session starts. Default 30 s.
  • Tone frequency (Hz) — the pitch of the beep. Higher = higher pitch. Default 1000 Hz (a clear mid tone).
  • Tone duration (ms) — how long each beep lasts. Default 150 ms (a short beep).
  • Response window (ms) — how long after a tone a TAP still counts as a reaction to it. After this, it is scored as a miss. Default 3000 ms (3 s).
  • Volume (0–1) — loudness of the tone, 0 = silent, 1 = loudest. Set this once with “Test sound” and keep it the same for everyone.
Keep all values identical across participants and both conditions.

Starting requires a tap (to unlock browser audio) and will try to go fullscreen. Put participant's headphones on and set volume with “Test sound” first.
