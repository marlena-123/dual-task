Your participant code

To match your data across the study securely and anonymously, please create a personal participant code. Build it using CAPITAL LETTERS and two-digit numbers (e.g. 05):

  • The last two letters of your father’s first name.
  • The number of letters in your mother’s first name (as a two-digit number, e.g. 05 or 10).
  • The day of your birthday (as a two-digit number, e.g. 05 or 23).

Example: father ANTON → last two letters ON; mother MARIA has 5 letters → 05; birthday on the 9th → 09. Final participant code: ON0509.

Advanced settings

Fade in/out is fixed at 10 ms. A tap within 100 ms of a tone is too early to be a real reaction and is recorded as a false alarm.

What these settings mean
  • Session length (minutes) — total run time. Default 20 min.
  • ISI min / max (s) — the gap between tones. Each gap is picked at random between these two values, so tones stay unpredictable. Default 5–10 s.
  • First probe not before (s) — a quiet lead-in so the first tone does not arrive immediately after the session starts. Default 10 s.
  • Tone frequency (Hz) — the pitch of the beep. Higher = higher pitch. Default 1000 Hz (a clear mid tone).
  • Tone duration (ms) — how long each beep lasts. Default 150 ms (a short beep).
  • Response window (ms) — how long after a tone a TAP still counts as a reaction to it. After this, it is scored as a miss. Default 2500 ms (2.5 s).
  • Volume (0–1) — loudness of the tone, 0 = silent, 1 = loudest. Set this once with “Test sound” and keep it the same for everyone.
Keep all values identical across participants and both conditions.
